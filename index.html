Que es KebianOS

KebianOS es un sistema operativo basado en Debian 13 el cual es una distribucion de Linux culla filosofia es la estabilidad extrema, y nosotros el equipo de KebianOS tomamos esa estabilidad extrema y le añadimos una capa de optimizaciones, tambien escojimos las mejores aplicaciones segun nuestros criterios y hasta donde lo legal nos deja, para facilitar el uso de nuestro sistema para usuarios nuevos en el mundo de linux, asi nos aseguramos que su experiencia sea lo mas comoda para los usuarios menos experimentados y ofrecemos una experiencia de usuario mucho menos pesadas para estos mismos, con una suit ofimatica OnlyOffice para que el usuario no experimente una mala experiencia al usar ofimatica y el navegador Brave para quitar las distracciones y pueda trabajar comodamente
